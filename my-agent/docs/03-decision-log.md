| Area | Decision | Reason |
|---|---|---|
| **LLM — Triage Agent** | `gemini-3.1-pro` | Best available Pro-tier reasoning for clinical decisions. Gemini 3.5 Pro is delayed; 3.1-pro is the current Pro flagship. **Meets hackathon eligibility: Gemini 3.5 or newer accessed via Gemini API** — `gemini-3.5-flash` is used for all other agents. |
| **LLM — All other agents** | `gemini-3.5-flash` | Released May 19, 2026. Frontier-level intelligence with speed & cost-efficiency. **Mandatory model per hackathon rules.** |
| **Agent framework** | Google ADK (`LlmAgent`, `SequentialAgent`) + Google Genkit | ADK for agent orchestration; Genkit for prompt/flow management. Both satisfy hackathon's mandatory agent framework requirement. |
| **Auth** | Firebase Authentication | No local password storage. Admin login via Firebase Auth REST API + Admin SDK token verification. Eliminates bcrypt credential leakage risk. |
| **Cloud deployment** | Cloud Run (FastAPI app) | Satisfies mandatory Google Cloud service requirement. Simple container deploy, scales to zero between demo runs. |
| **Audit storage** | Firestore (Firebase Admin SDK) | Serverless, minimal setup, real-time capable. Doubles as the "auditability" story from the original pitch. |
| **Hospital data** | OpenStreetMap Overpass API | Free, no API key, SLA-free but cacheable. Returns real hospital names + GPS. Explicitly NOT Google Places API (no billing required for demo). |
| **Routing/ETA** | OSRM public demo server | Free, no API key. Returns real driving distance + duration. Cache results locally after first pull to guard against demo-day flakiness. |
| **Bed/specialty data** | Simulated, generated by `lifeline seed` | Real EHR bed data requires private HL7/FHIR hospital integration — explicitly out of scope. Documented in README real vs. simulated table. |
| **Triage scoring** | NEWS2 (Royal College of Physicians, public standard) | Grounds Triage Agent's reasoning in a real clinical formula. Agent receives the computed score — not raw vitals — so Gemini reasons over a real number. |
| **Demo city** | `mumbai` (default; configurable via admin panel) | Dense hospital network in OSM. Configurable to any supported city via `DEMO_CITY` setting. |
| **Front end** | React + Vite (TypeScript/Tailwind) | Replaces Streamlit to target the "Best Multimodal UX" category. Enables highly polished "product" feel, custom state management, and real-time UI components. |
| **Demo input mode** | Preset scenarios | Reliability over flexibility for a live/recorded demo. Preset payloads sent from React UI. |
| **Stretch agents** | Routing Agent + Briefing Agent are OPTIONAL | Only built if Day 1–2 finish early. See `07-scope-lock.md`. |
| **Model registry** | `lifeline/models.py` — single source of truth | All agents import `AGENT_MODELS[agent_name]`. Upgrade all models by editing one file. |
